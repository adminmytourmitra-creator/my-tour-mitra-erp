# My Tour Mitra ERP

Travel Agency Management & Operations ERP for **My Tour Mitra**.

This system is designed to manage travel agency operations, customer relationships, quotations, bookings, invoices, vouchers, payments, expenses and business reporting from one centralized application.

---

## Project

**Project Name:** My Tour Mitra ERP  
**Business:** My Tour Mitra  
**Platform:** Web Application  
**Database:** Firebase Firestore  
**Authentication:** Firebase Authentication  
**Hosting:** Firebase Hosting  

---

# Main Modules

The ERP contains the following major modules:

1. Dashboard
2. Customers
3. Enquiries
4. Follow-ups
5. Packages
6. Hotels
7. Cabs
8. Agencies
9. Quotations
10. Bookings
11. Invoices
12. Vouchers
13. Payments
14. Expenses
15. Profit & Loss
16. Team
17. Settings
